jQuery

Una biblioteca de JavaScript que simplifica algunas tareas con elementos HTML.

¿Qué es jQuery?

jQuery se publicó en 2006 y ofrece métodos para seleccionar elementos, trabajar con eventos, hacer efectos y realizar solicitudes de datos.

Ventajas

  • Sintaxis corta para algunas tareas.
  • Incluye métodos de animación.
  • Es útil en proyectos antiguos.

Desventajas

  • Necesita cargar una biblioteca adicional.
  • Muchas tareas se resuelven hoy con JavaScript nativo.
