JSON

Un formato de texto utilizado para representar e intercambiar datos.

¿Qué significa JSON?

JSON significa JavaScript Object Notation. Organiza datos mediante pares de clave y valor, objetos y arreglos.

  • Las claves y cadenas usan comillas dobles.
  • Admite cadenas, números, booleanos, null, objetos y arreglos.
  • No permite comentarios ni comas sobrantes al final.
{
  "nombre": "Minecraft",
  "precio": 29.99,
  "disponible": true
}
